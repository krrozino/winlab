## Arquivos extras do pacote piloto

```text
PILOT-DEPLOYMENT-CHECKLIST.txt
PILOT-ROLLBACK-CHECKLIST.txt
pilot-readiness.json
preflight-source.json
```

Todos entram no manifest e recebem SHA-256.

## Gates

O pacote piloto fica bloqueado quando:

- configuração contém erro fatal;
- preflight não foi importado;
- perfil do preflight não corresponde à configuração;
- preflight possui BLOCK;
- máquina alvo não está identificada.

WARN não bloqueia, mas aparece no pacote e deve ser revisado.

## Segurança adicional

Mesmo que o usuário configure:

```text
AppLocker = Enabled
Profile cleanup = Delete
```

o **pacote piloto** usa:

```text
AppLocker = AuditOnly
Profile cleanup = ReportOnly
```

A configuração original não é alterada na interface.

## Gate automatizado final

- testes unitários;
- typecheck;
- build Next.js;
- Windows PowerShell 5.1;
- PowerShell 7;
- AppLocker XML;
- package integrity e tamper detection;
- execução/contrato do preflight;
- geração e validação do pacote piloto.

Nenhuma dessas etapas dispara deployment automático na Vercel.
